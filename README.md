## Как запустить

Игра работает **локально в любом современном браузере** (установка не требуется):

1. Скачайте готовый архив `Pink_Pilled_RU_v1.1.zip` со страницы **[Release v1.1](https://github.com/SlopCoreGames/pink-pilled-RUS/releases/latest)** *(или клонируйте репозиторий)*:
   ```bash
   git clone https://github.com/SlopCoreGames/pink-pilled-RUS.git
   ```
2. Распакуйте архив целиком в отдельную папку (важно, чтобы рядом с [`index.html`](index.html) лежала папка `pic/`).
3. Откройте [`index.html`](index.html) двойным кликом в браузере (Chrome, Edge, Firefox и др.).
