## Как запустить

Игра работает **локально в любом современном браузере** (установка не требуется):

1. Скачайте репозиторий (**Code → Download ZIP**) или клонируйте его:
   ```bash
   git clone https://github.com/SlopCoreGames/pink-pilled-RUS.git
   ```
2. Распакуйте архив (важно, чтобы рядом с `index.html` лежала папка `pic/`).
3. Откройте [`index.html`](index.html) двойным кликом в браузере (Chrome, Edge, Firefox и др.).

## О переводе

- **Объём:** переведены все **583 пассажа** (`~957 тыс.` символов), включая интерфейс, кнопки переходов и описания.
- **Сохранение механик SugarCube:** в ходе автоматического перевода все переходы `[[...|Target]]`, макросы `<<if>> / <<set>> / <<link>> / <<button>>`, переменные (`$...`) и HTML-теги были замаскированы и проверены на целостность — ни одна игровая переменная или ссылка не сломана (`0` протекших масок).
- **Модель:** локальный перевод выполнен без цензуры моделью **Gemma 4 26B A4B Abliterated (`Q5_K_M`)** через `llama.cpp`.
